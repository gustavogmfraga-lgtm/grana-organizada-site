Grana Organizada

Política de Privacidade

Última atualização: 17 de outubro de 2026

1. Quem somos

O Grana Organizada é um projeto de vídeos de educação financeira pessoal publicados no YouTube. Esta política descreve como o aplicativo "Grana Organizada" (a ferramenta interna de produção de vídeos do canal) trata informações. O responsável pelo tratamento é a equipe do Grana Organizada; a razão social e o CNPJ serão informados aqui quando a empresa responsável for constituída. Contato: granaorganizada.mkt@gmail.com.

2. O que o aplicativo faz

O aplicativo é usado somente pela equipe do canal. Ele monta vídeos de educação financeira e publica esses vídeos no canal do YouTube do próprio Grana Organizada. Não é um serviço aberto ao público: ninguém além da equipe faz login nele.

3. Dados acessados por meio das APIs do Google

Quando a pessoa responsável pelo canal autoriza o aplicativo na conta Google do canal, ele solicita estas permissões:

  • YouTube Data API — envio de vídeos (youtube.upload): para enviar os vídeos produzidos ao canal Grana Organizada.
  • YouTube Data API — gerenciamento do canal (youtube.force-ssl): para confirmar em qual canal um vídeo foi publicado e apagar vídeos de teste criados pelo próprio aplicativo.
  • Google Drive — arquivos criados pelo aplicativo (drive.file): para guardar, em pastas da equipe, os arquivos de produção (áudios de narração e imagens) criados pelo próprio aplicativo. Esta permissão não dá acesso aos demais arquivos do Drive.

O aplicativo guarda apenas o token de autorização (refresh token) necessário para continuar funcionando, em um cofre de variáveis protegido do servidor da equipe.

4. Para que usamos esses dados

Usamos o acesso exclusivamente para as finalidades acima: publicar vídeos do canal e armazenar os arquivos de produção. Não usamos os dados para publicidade, não criamos perfis de pessoas e não vendemos nem alugamos nenhuma informação.

5. Compartilhamento

Não compartilhamos dados obtidos das APIs do Google com terceiros. O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google obedecerão à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Armazenamento e retenção

Os arquivos de produção ficam no Google Drive da equipe e os vídeos ficam no YouTube, nas contas da própria equipe. O token de autorização é mantido apenas enquanto o aplicativo estiver em uso e é apagado quando o acesso é revogado ou o projeto é encerrado.

7. Como revogar o acesso

Você pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions. Ao revogar, o aplicativo deixa de conseguir acessar a conta.

8. Este site

Este site é estático e informativo. Ele não usa cookies, não tem formulários e não coleta dados de quem o visita.

9. Seus direitos (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode pedir confirmação de tratamento, acesso, correção ou exclusão de dados que porventura tratemos sobre você. Escreva para granaorganizada.mkt@gmail.com.

10. Alterações

Podemos atualizar esta política. A data de "última atualização" no topo indica a versão em vigor.
